# PYXEL PATTERN MAKER 作成中
Pyxel専用のパターン作成ツールです。画像として保存することができます。

## HOW TO USE
|キー|使い方|
|-|-|
|[←]|色の変更|
|[→]|色の変更|
|[X]|黒に戻す|
|[C]|クリア|
|[P]|プレビューモード（実際のサイズで画面全体に並べて表示します。）|
|[S]|作成した画像の保存|
|*表示サイズ関連*|
|[Q]|表示サイズ小（64px）|
|[W]|表示サイズ中（96px）|
|[E]|表示サイズ大（128px）|
|[R]|表示サイズ特大（160px）|
|*パレットサイズ関連*|
|[1]|パレットサイズを8pxへ変更する|
|[2]|パレットサイズを16pxへ変更する|
|[3]|パレットサイズを32pxへ変更する|
|[4]|パレットサイズを48pxへ変更する|
